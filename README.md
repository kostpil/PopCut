# 🎬 PopCut

**PopCut** is a full-stack movie community web application where users can discover films, track their watched movies, write reviews, and explore what the community is watching in real time.

🔗 **Live Demo:** [popcut.vercel.app](https://popcut.vercel.app)

---

## ✨ Features

- **Movie Discovery & Search:** Browse featured films via an interactive carousel and search across the movie catalog.
- **User Reviews & Community Feed:** Share personal movie reviews, edit or delete your entries, and view recent community activity live on the homepage.
- **Personal Watchlist & History:** Keep track of watched movies and manage your personal profile.
- **Responsive Single Page Application (SPA):** Fast client-side navigation with seamless state updates.

---

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript (ES6+), CSS3, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Deployment & Hosting:** Vercel (Frontend), Railway (Backend & Database)
